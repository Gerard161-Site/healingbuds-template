# Healing Buds Video Hero Template

**Version:** 1.0.0  
**Author:** Healing Buds Design Team  
**Category:** Medical Cannabis

## Overview

A premium, immersive template featuring full-screen video backgrounds with smooth parallax scrolling effects. Designed specifically for medical cannabis dispensaries that want to convey professionalism, innovation, and trust.

## Key Features

- **Full-Screen Video Hero**: Captivating video background with customizable overlay
- **Parallax Scrolling**: Smooth depth effects throughout the page
- **Scroll Fade Effects**: Dynamic content reveals as users scroll
- **Medical Aesthetic**: Professional design suitable for healthcare compliance
- **Fully Responsive**: Optimized for all devices
- **WCAG 2.1 AA Compliant**: Accessible to all users

## Customization

This template automatically adapts to tenant branding:

- **Business Name**: Displays in hero section
- **Logo**: Optional overlay in hero
- **Video**: Uses tenant's `heroVideoUrl` or falls back to image
- **Colors**: Adapts to `primaryColor`, `secondaryColor`, `accentColor`
- **Fonts**: Uses tenant's `fontFamily` and `headingFont`
- **Tagline**: Custom tagline from tenant settings

## Sections

1. **Video Hero** - Immersive full-viewport introduction
2. **About** - Brief business introduction
3. **Value Propositions** - Key benefits grid
4. **Cultivation** - Quality and process information
5. **International Standards** - Compliance badges
6. **News** - Latest updates and articles

- **Framework**: Next.js 14
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Performance**: Lighthouse 92+
- **Bundle Size**: ~145KB
